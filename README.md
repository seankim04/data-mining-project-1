# Data Mining Project 1

## Files
- `Data Mining Project 1.ipynb` - implementation / experiments
- `Concrete_Data.xlsx` - dataset (UCI Concrete Compressive Strength)

## Setup
1. Clone the repo:
   git clone https://github.com/seankim04/data-mining-project-1.git
   cd data-mining-project-1

## Reproducing the results
1. Launch Jupyter:
   jupyter notebook "Data Mining Project 1.ipynb"
2. Run all cells in order.
3. Keep `Concrete_Data.xlsx` in the same folder as the notebook.
